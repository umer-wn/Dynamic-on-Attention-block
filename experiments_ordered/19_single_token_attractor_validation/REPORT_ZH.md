# 实验19：这些循环轨迹是真正的稳定吸引子吗？

## 一句话结论

原始完整协议找到了能够闭合的周期轨道候选，但没有候选通过旧的“10周期、相位不变距离、恢复率≥0.9”门槛。新增的稠密 checkpoint 简化协议中，`step48000` 同时表现为严格闭合、Floquet `stable` 且256步平均响应增益小于1，是目前最强的稳定周期候选；但它只检验了一个代表 token，仍不能写成已经普遍验证的稳定周期吸引子。

## 为什么要做这个实验

此前的二维投影中出现了圆环或重复轨迹。但一张投影图无法区分：

- 真正的周期轨道；
- 很长的瞬态；
- 接近周期但仍缓慢漂移的轨迹；
- 不稳定周期轨道；
- 投影后看起来像圆环、在完整512维状态中却没有闭合的轨迹。

实验19的目标就是逐层排除这些情况。

## 整个实验只需要理解三道关卡

### 第一关：轨迹能不能真正闭合？

先在长轨迹中寻找候选周期 (p)，即检查：

\[
x_{t+p}\approx x_t
\]

这一步叫“周期回归筛选”，含义是走了 (p) 步以后是否回到原位置附近。

找到候选后再做“多点射击”：同时微调周期上的所有状态点，使每个点经过一次模型映射后准确连接到下一个点。它解决的是“看起来绕了一圈”和“数学上闭合成环”之间的差别。

本实验规定闭合残差不超过 `1e-5` 才通过。最终288条相位记录全部通过，残差中位数为 `4.35e-7`，说明这些候选的几何闭合质量很好。

### 第二关：闭合轨道附近是收缩还是扩张？

对一个完整周期上的雅可比矩阵连续相乘，得到 monodromy matrix (M)。它描述微小偏差绕轨道一整圈后如何变化。

这里只需要看最大 Floquet 乘子模 ρ(M)：

- `stable`：ρ(M) < 0.98，并且两种Krylov估计差异小于5%；局部小偏差倾向收缩。
- `unstable`：ρ(M) > 1.02；至少有一个方向明显扩张。
- `boundary`：接近1或数值证据不足；不能明确归类。

注意：这里的 `stable` 只代表周期附近的线性局部收缩，不等于已经证明它是吸引子。

### 第三关：加入真实扰动后会不会回来？

对每条轨道施加：

- 16个随机方向；
- 3个相对尺度：`1e-6、1e-4、1e-2`；
- 共48次扰动；
- 扰动后继续运行10个周期。

距离计算会在整条周期轨道上寻找最近相位，所以单纯沿环发生相位移动不会被误判为失败。

若最终距离不超过初始扰动距离，就记为一次恢复。恢复率至少达到0.9，才认为具有足够的有限扰动吸引证据。

本实验没有任何系统达到0.9，最高系统级恢复率只有0.375。因此没有候选通过最后一关。

## 稠密 checkpoint 扩展（本次新增）

### 扩展范围如何确定

本次不重新扫描所有3型，而是复用现有周期数据：对每个 checkpoint 的4个固定展示 token（`clones / motive / cabinet / miles`）读取候选周期，只有 checkpoint 的候选周期中位数大于1才进入实验。原实验已有的 `step10000` 也保留，因此共21个 checkpoint。`step27000` 只有1/4 token 给出非平凡周期，中位数仍为1，所以未执行。每个 checkpoint 从非平凡周期 token 中选取周期误差最小者作为代表。

这是为覆盖更多 checkpoint 设计的简化协议：每个 checkpoint 只验证一个代表 token，使用已有1024步轨迹，而不是原实验的3个状态库、8个token和4096步。因此它用于发现值得深入验证的 checkpoint，不覆盖也不推翻上面的原始完整实验。

### 新的256步扰动指标

在动态步768的代表状态上，对完整512维状态施加8个独立随机单位方向和3个相对尺度 `1e-6、1e-4、1e-2`，共24次扰动。每个方向都会同时扰动全部512个维度，而不是只改某一个坐标；方向由固定随机种子生成，可复现。

扰动状态和未扰动参考状态一起演化256步，计算

\[
g_i=\frac{\|\widetilde x_{1024}^{(i)}-x_{1024}\|_2}
{\|\widetilde x_{768}^{(i)}-x_{768}\|_2}.
\]

- 算术平均增益 `mean gain < 1`：24次扰动平均缩小；`> 1`：平均放大。这是本次主指标。
- 几何平均增益用于描述典型的乘性变化，避免少量极端方向完全支配结果，但不替代算术平均。
- `收缩方向占比` 是24次中 `g_i<1` 的比例。

该指标比较相同动态步上的扰动与未扰动状态，允许真实轨迹漂移，但没有对周期相位做最小化，也不等价于旧协议的“返回整条周期轨道”。

\[
r_i=\frac{\|F(x_i)-x_{i+1\bmod p}\|_2}{S_{orbit}}
\]

### `norm` 大小与FP32精度核查

实际代码为：

```python
reference = start.reshape(1, -1)
perturbed = reference + eps * reference.norm(dim=-1, keepdim=True).clamp_min(1.0) * unit
```

所以题目中的 `norm` 是扰动注入时（动态步768）完整512维状态 `x` 的L2范数 `||x||₂`，不是轨迹半径、单维标准差或归一化Frobenius范数。所有状态范数都远大于1，`clamp_min(1.0)` 没有实际作用。

- 21个checkpoint由已记录初始距离反推的 `norm` 范围约为 `39.62–65.23`，中位数约 `54.33`；
- 因而三个尺度的目标L2扰动通常约为 `5.4e-5、5.4e-3、5.4e-1`；
- 对20个有原始step768状态的checkpoint复现全部480次注入后，`1e-6` 的实际/目标L2比值为 `0.9971–1.0037`，方向余弦为 `0.99955–0.99975`，说明整体扰动长度和方向没有失真；
- 但 `1e-6` 的典型单坐标扰动只有约 `12.8 ULP`，第10百分位仅约 `2.0 ULP`，中位数约 `2.54%` 的坐标加扰后数值不变。它确实触及了分量级FP32精度边缘；
- `1e-4` 的典型分量约 `1282 ULP`，方向余弦数值上为1，几乎没有坐标丢失；`1e-2` 更远离精度边缘。

因此，`1e-6` 不是“完全没有注入成功”，但不适合与较大尺度等权作为256步响应的主结论。尤其其初始L2距离中位数只有 `5.44e-5`，256步后距离中位数为 `8.39e-5`，响应很容易受到长期FP32量化与微小方向差异影响。后续主报告应优先使用 `1e-4、1e-2` 稳健尺度汇总，同时保留 `1e-6` 作为小扰动敏感性附录。

## 最重要的观察

1. **闭合周期确实存在。** step10000、29000、41000和57000都找到了高精度闭合轨道。
2. **没有发现不动点。** 所有最终最小周期都大于1，没有 `p=1`。
3. **step57000最接近稳定周期吸引子。** 它有最多的局部stable标签，也有最高扰动恢复率，但仍远低于0.9门槛。
4. **Floquet stable不能单独作为最终结论。** step41000和57000虽然出现stable记录，但有限扰动没有可靠返回。
5. **原始完整协议的结论仍是“存在周期轨道候选，但没有验证出稳定吸引子”**，不是“模型中没有周期结构”。
6. **稠密扩展把step48000定位为新的优先复核点。** 它通过简化协议的三项检验，但证据覆盖面弱于原始完整实验，因此报告为“最强稳定周期候选”，不直接升级为普遍稳定吸引子。

## 三种初始状态库是什么

为了避免结论只依赖token embedding，实验从三类初态启动：

- `native`：当前checkpoint自身的token embedding；
- `common_step0`：固定使用step0模型的同一批token embedding；
- `random_matched`：随机方向，但整体范数与step0 embedding匹配。

## 回归和多点射击的区别

- 周期回归是在原始轨迹里找“隔 (p) 步后很接近”的片段，用来提出候选。
- 多点射击是在候选基础上主动调整整圈状态，使所有相邻段严格首尾相接，用来验证闭合。

可以把它理解为：回归是在照片中发现一个像圆的轮廓；多点射击是检查并修正这个轮廓，使它真正闭合。

## 哪些结论不能从本实验得到

- 不能把二维投影中的圆环直接称为极限环；本实验使用的是完整512维状态。
- 不能把单步雅可比谱半径或归一化Frobenius范数等同于周期稳定性；周期稳定性看的是一整圈的monodromy/Floquet结果。
- 不能把局部 `stable` 标签直接写成“稳定吸引子”；还需要扰动恢复。
- 精度审计和架构消融不在本简化报告展开，也不作为第四阶段的最终判定门槛。

## 推荐的组会表述

> 我首先在长轨迹中筛选周期回归，然后用多点射击验证512维状态是否真正闭合，再用Floquet乘子判断周期附近的局部稳定性，最后加入多尺度扰动。原始完整实验中的候选都没有达到90%的相位不变恢复率，所以它只支持存在周期轨道，尚未验证出稳定吸引子。随后我把简化协议扩展到21个有非平凡周期的checkpoint，并把扰动改为8个方向、3个尺度、256步响应增益；step48000同时通过严格闭合、Floquet stable和平均扰动收缩，是下一轮最值得用完整多token协议复核的稳定周期候选。
