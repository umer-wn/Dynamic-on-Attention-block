# Experiment Directory Convention

Each new experiment should live under `experiments/<experiment_name>/` and keep the three research artifacts aligned:

- `plan/`: the experiment plan, expected outputs, resource notes, and stopping criteria.
- `results/`: raw, processed, and figure outputs produced by the scripts.
- `reports/`: final observations, deviations from the plan, and links to important result files.
- `configs/`: the exact config used for the run when the experiment is self-contained.

Figures generated by `scripts/analyze_dynamical_poincare.py` must have a neighboring `.md` note and a figure manifest in `results/figures/`.
